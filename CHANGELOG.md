# Changelog

All notable changes to Vaultr are documented here.

## [1.0.0] - 2026-08-03

### Added

- Open-source release of Vaultr, a local-first AI legal assistant for private legal work.
- Private Mode with local Ollama inference, SQLite persistence, and browser-side storage.
- Multi-provider model support, legal research, RAG over user documents, matter management, and contract risk scanning.
- Tauri desktop packaging for macOS, Windows, and Linux.
- Contributor documentation, security guidance, community health files, and continuous integration checks.

### Security

- Dependency audit baseline is clean locally.
- API keys, local app data, desktop signing material, and development context files are excluded from version control.
- Authentication, request-size limits, rate limiting, and privacy-preserving local identity handling are documented in the repository.
